# Pasta Assets - Galeria do Mirante

Esta pasta contém as imagens que serão exibidas no carrossel automático da seção "Galeria do Mirante".

## Como Adicionar Suas Fotos

1. **Escolha as fotos** do Instagram do Mirante de Laranjeiras que deseja usar
2. **Baixe as imagens** em alta qualidade
3. **Renomeie as imagens** seguindo o padrão:
   - `foto1.jpg`
   - `foto2.jpg`
   - `foto3.jpg`
   - `foto4.jpg`
   - `foto5.jpg`
   - etc...

4. **Coloque as imagens** nesta pasta (`assets/`)
5. **Faça upload** para o GitHub

## Tipos de Fotos Recomendadas

- 📷 Fotos do Deck da Piscina
- 🍽️ Pratos e comidas
- 🎉 Festas e eventos
- 🌅 Vistas do Mirante
- 🏨 Ambiente interno
- 🍸 Drinks
- 👥 Momentos especiais

## Formato das Imagens

- **Formato**: JPG ou PNG
- **Tamanho recomendado**: 1200x800px ou maior
- **Qualidade**: Alta qualidade (não comprimidas)

## Carrossel Automático

O carrossel irá:
- ✅ Exibir as imagens automaticamente
- ✅ Passar da direita para esquerda continuamente
- ✅ Pausar ao passar o mouse
- ✅ Mostrar o nome da imagem na parte inferior

## Instruções para Atualizar

1. Adicione as imagens nesta pasta
2. Faça commit e push para o GitHub
3. As imagens aparecerão automaticamente no site!

---

**Nota**: O site está configurado para buscar todas as imagens nomeadas como `foto*.jpg` ou `foto*.png` nesta pasta.
